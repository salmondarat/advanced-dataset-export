# Contributing to Advanced Dataset Exporter

Terima kasih telah tertarik untuk berkontribusi!

## Cara Berkontribusi

1. **Fork** repositori ini.
2. Buat _feature branch_ baru: `git checkout -b fitur-baru-kamu`.
3. Lakukan perubahan pada skrip `.jsx` atau dokumentasi.
4. Lakukan pengujian langsung di Adobe Illustrator untuk memastikan skrip berjalan tanpa bug.
5. Commit perubahan kamu: `git commit -m 'Menambahkan fitur X'`.
6. Push ke branch kamu: `git push origin fitur-baru-kamu`.
7. Buat **Pull Request**.

## Laporan Bug

Jika kamu menemukan issue atau error saat ekspor:

- Sertakan versi Adobe Illustrator yang kamu gunakan.
- Sertakan OS (Windows / macOS).
- Lampirkan pesan error yang muncul di Script Alert jika ada.
